# Покупки

Общий список покупок на телефон и компьютер. Живёт на GitHub Pages и Firebase, без установки из магазина приложений.

Рабочий пример: [dmitryrt.github.io/pokupki](https://dmitryrt.github.io/pokupki/?l=pokupki01)

Список видят только те, кто вошёл через Google и кого пустили в семью. Номер телефона для SMS в репозиторий не попадает — он хранится только на устройстве.

## Как пользоваться

1. Откройте ссылку в браузере и войдите через Google.
2. Первый вошедший становится хозяином списка.
3. Чтобы пустить второго человека: кнопка «отправить» → **Пустить ещё одного** → второй открывает ту же ссылку и входит своим Google.
4. Дальше вход запоминается. Google снова просить не будет, пока не нажмёте «Выйти» или не почистите браузер.

На телефоне:

| | |
|---|---|
| Добавить | строка внизу, Enter |
| Купили | короткий тап по пункту |
| Исправить опечатку | зажать пункт ~0,5 сек |
| Новый список | крестик в шапке |
| «Пора за покупками» | самолётик — откроет SMS. Долгое нажатие меняет номер |

### iPhone

Не заходите со старой иконки на экране «Домой»: Google из неё ломается (`The requested action is invalid`).

1. Откройте **Safari** (иконка компаса), не Chrome.
2. Откройте ссылку списка и войдите Google.
3. Safari запомнит вход. В следующий раз список откроется сам.
4. Если нужна иконка на экране: **Поделиться → На экран «Домой»** уже после входа.

На Android можно сразу добавить ярлык из Chrome: вход Google там работает как на компьютере.

## Сделать свой список

Нужны бесплатные аккаунты GitHub и Google. Платный тариф Firebase не нужен — хватает Spark.

### 1. Свой репозиторий

1. Нажмите **Fork** у [Dmitryrt/pokupki](https://github.com/Dmitryrt/pokupki) или скопируйте файлы в новый репозиторий.
2. Репозиторий должен быть **публичным**: бесплатный GitHub Pages иначе не откроет сайт.
3. GitHub → **Settings → Pages → Deploy from a branch** → ветка `main`, папка `/`.
4. Сайт будет по адресу `https://ВАШ_НИК.github.io/ИМЯ_РЕПО/`.

### 2. Подставить свои адреса

В `index.html` и `manifest.webmanifest` замените все `dmitryrt.github.io/pokupki` на свой адрес.

В `index.html` поменяйте идентификатор списка, 8–32 латинских буквы или цифры:

```js
const FAMILY_ID = "moyaspisok12";
```

Не оставляйте чужой `pokupki01` и чужие ключи Firebase — иначе попадёте в чужой список или создадите свой рядом с чужим.

### 3. Firebase

1. [console.firebase.google.com](https://console.firebase.google.com) → новый проект.
2. Добавьте веб-приложение, скопируйте `firebaseConfig` в `index.html` вместо текущего блока.
3. **Build → Realtime Database → Create** → регион `europe-west1` (или любой, главное чтобы `databaseURL` совпал с тем, что в конфиге).
4. Сразу вставьте правила из `database.rules.json` и нажмите **Publish**. Файл в GitHub сам в консоль не попадает: без Publish список либо открыт всем, либо никому.
5. **Authentication → Sign-in method → Google → Enable**. Почту поддержки укажите свою. Поля SHA-1 и Web client ID оставьте пустыми, **Save**.
6. **Authentication → Settings → Authorized domains** — добавьте `ВАШ_НИК.github.io` (без `https://`).

После пуша в `main` подождите минуту и откройте свой Pages-адрес. Первый Google, которым войдёте, станет хозяином списка.

### 4. Второй человек в семье

Хозяин нажимает **Пустить ещё одного**, второй открывает ту же ссылку и входит своим Google. Пока кнопка не нажата, чужой аккаунт увидит «список уже занят».

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | весь интерфейс и логика |
| `manifest.webmanifest` | имя, иконка, адрес для ярлыка |
| `database.rules.json` | кого Firebase пускает к списку |
| `icon-*.png`, `apple-touch-icon*.png` | иконки на телефон |

Телефон для самолётика пишется в `localStorage` браузера, в git его класть не нужно.

## Если не пускает

- **The requested action is invalid** на iPhone — откройте ту же ссылку в Safari, не с иконки на экране.
- Вход есть, списка нет — в Firebase Console правила из `database.rules.json` не опубликованы.
- Google-окно сразу закрывается — в Authorized domains нет `вашник.github.io`.
- «Список уже занят» — хозяин ещё не нажал «Пустить ещё одного».
